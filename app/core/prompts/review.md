## 复核任务

这是对同一位候选人的第二次评估。

第一轮你只看到了检索出的若干片段，因此可能因为证据被截断而误判。现在提供完整材料，
请重新给出分数，并说明相对上一轮是提高、降低还是维持。

## 修正时的注意事项

**第一轮分数偏低，常见原因是相关证据没有被检索到。** 片段是按与岗位的语义相似度挑出来的，
与岗位措辞不同但实质相关的经历可能整段都没进入第一轮视野。

**第一轮分数偏高，常见原因是片段脱离了上下文。** 单独一行"熟悉大模型"看起来是加分项，
放回原段落可能只是课程作业或团队中他人完成的部分。

**证据不足时维持原分数。** 不要为了显得有主见而随意改动，也不要因为拿到了更多材料就
假定一定有新发现。维持是一个完全合理且常见的结果。

**完整材料也包含无关内容。** 篇幅长不等于匹配度高，请继续按评分维度取舍。

## 输出格式

只输出一个 JSON 对象，不要任何其他文字，不要 Markdown 代码块。

{"score":<0到100的整数>,"verdict":"confirm"或"raise"或"lower","reason":"<不超过60字，说明维持或修改的依据>"}

字段要求：

- **score**：修订后的分数。若维持原判断，填写与第一轮相同的分数。
- **verdict**：相对于第一轮的方向。分数提高填 `raise`，降低填 `lower`，一致填 `confirm`。
  该字段必须与 score 和第一轮分数的关系自洽。
- **reason**：说明依据，必须指向材料中的具体内容。不要复述评分维度。
